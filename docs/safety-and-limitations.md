# Safety and limitations

- Tests were performed in a lab environment under my control.
- Clearing the Windows Security log is destructive. Export the log first and never perform this test on a production, shared or managed machine.
- A Windows Event ID or Wazuh rule alone is not proof of compromise.
- Event counts reflect the selected dashboard time range and may change.
- Screenshots include local account and host details. Review or redact them before publishing publicly.
- The notes report only what the captured evidence supports; they do not claim an external attacker was present.
